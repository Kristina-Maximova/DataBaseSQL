# DataBaseSQL
Приложение для сбора данных о вакансиях
и сохранении полученных данных в базе данных. 

Поиск проводится на платформе  [HeadHunter](https://hh.ru/vacancy)

Для работы с базой данной приложение выполняет поиск по запросам.

## Для использования

Клонируйте репозиторий [GitHub](https://github.com/Kristina-Maximova/DataBaseSQL)
Установите необходимые зависимости:

- python = "^3.13"
- requests = "^2.32.3"
- psycopg2 = "^2.9.10"

В корне проекта должен быть создан файл 
database.ini по образцу database_example.ini
